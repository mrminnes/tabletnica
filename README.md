# Мои таблетки — Android-приложение (v1)

Веб-приложение, обёрнутое в нативную оболочку через **Capacitor**. Версия 1: отметка приёма одним нажатием (без фото), учёт запаса, напоминания-уведомления, данные хранятся на устройстве (localStorage — в отличие от прототипа в чате, здесь всё сохраняется между запусками).

## Способ 1: сборка в облаке через GitHub — без Android Studio

В проекте уже лежит `.github/workflows/build-apk.yml`. GitHub соберёт APK сам:

1. Создай **приватный** репозиторий на github.com и загрузи туда все файлы проекта
   (как делал с прошлыми проектами: `git init`, `git add .`, `git commit`, `git push`).
2. Сборка запустится автоматически после push. Ход виден во вкладке **Actions**
   (можно перезапустить вручную: Actions → Build APK → Run workflow).
3. Через ~5 минут открой завершившийся запуск, внизу в разделе **Artifacts**
   скачай `med-tracker-apk` — это zip, внутри `app-debug.apk`.
4. Перекинь `app-debug.apk` на телефон и установи (разреши установку из
   неизвестных источников). Готово.

Это debug-сборка — для себя и семьи её достаточно. Для публикации в RuStore
понадобится подписанная release-сборка (см. ниже про keystore).

## Способ 2: локальная сборка

### Что нужно установить один раз

1. **Node.js** (LTS) — https://nodejs.org
2. **Android Studio** — https://developer.android.com/studio (при первом запуске установит Android SDK)

## Сборка APK — по шагам

Открой терминал в папке проекта и выполни:

```bash
npm install              # ставим Capacitor
npx cap add android      # создаёт папку android/ с нативным проектом
npx cap sync             # копирует www/ внутрь android-проекта
npx cap open android     # открывает проект в Android Studio
```

В Android Studio:

1. Дождись окончания синхронизации Gradle (полоска внизу).
2. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk` — его можно установить на телефон (разреши установку из неизвестных источников).

Для быстрого теста на подключённом по USB телефоне: включи «Отладку по USB» и нажми ▶ (Run) в Android Studio.

## После изменения кода

Весь интерфейс и логика — в одном файле **`www/index.html`**. После правок:

```bash
npx cap sync && npx cap open android
```

и пересобери APK.

## Уведомления

- Приложение само запросит разрешение на уведомления при первом запуске (Android 13+).
- Напоминания планируются локально для каждого лекарства × время × день недели и повторяются еженедельно. Интернет не нужен.
- На некоторых телефонах (Xiaomi, Huawei и т.п.) нужно разрешить приложению «автозапуск» / убрать из энергосбережения, иначе система может глушить уведомления.

## Кастомизация

- **Название приложения и ID**: `capacitor.config.json` (`appName`, `appId`). Менять ID лучше до `npx cap add android`.
- **Иконка и сплэш**: проще всего через `npx @capacitor/assets generate` — положи `icon.png` (1024×1024) в папку `assets/` в корне проекта.
